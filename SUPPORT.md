# QuarryFi VS Code Extension Support

Before opening an issue:

1. Run **QuarryFi: Show Tracking Status**.
2. Check **View → Output → QuarryFi** for an HTTP status or connection error.
3. Confirm the active workspace is assigned to the intended profile.
4. Confirm the API key is assigned to an active team member in the [QuarryFi Team dashboard](https://quarryfi.com/dashboard/team).

Please include the extension version, VS Code version, operating system, and redacted error text. Never paste an API key, source code, file contents, full file paths, or the contents of your audit log into a public issue.

Report bugs at <https://github.com/quarryFi/vscode-extension/issues>.
